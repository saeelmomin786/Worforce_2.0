Included on paid plans

History & memory is part of Basic, Pro and Enterprise. It is not included on Free. Building one file into memory uses one task. Searching existing memory does not use tasks and works without an AI request. Institutional Memory Preservation That Keeps Your Business Data Local

Different information, kept separate

The system separates your documents, generated work, editable skills, writing style and things people said to you. That separation is designed to prevent a customer’s remark being treated as company policy or confidential business notes being pulled into an unrelated outgoing reply. Review sensitive output before sharing it.

Search locally by words and meaning

Files are read and indexed on your computer. Search combines exact words with meaning, so both an invoice number and a differently worded description can help find the right document. Local indexing and searches can run offline.

See how documents connect

Point the app at a folder to build a map of the people, subjects and relationships inside it, with a written summary. Overnight processing organizes recurring facts, patterns of work and your writing preferences.

Correct it in a text editor

Memory is stored in ordinary text files. Open them in Notepad, Obsidian or another editor to correct information. Your edits survive rebuilds. If you stop using Workforce, the folder and its readable files stay with you.

Share knowledge with your team

Organisation members can share notes, reference material and the conversations behind decisions. Changes sync hourly in both directions through your own Drive, with a local copy on each machine. This helps preserve knowledge when roles change; it is not real-time collaboration.

Understand the data boundary

Local storage and indexing do not make AI work fully offline. AI requests go to the provider used for that work. Optional team sharing transfers information through your Drive. Read the data page and Privacy Notice before using sensitive material.
