Share more than documents

Team sharing includes notes, memory, reference material and the conversations behind decisions. It can also share saved routines, workers, dashboards, task boards, sales pipelines, engine setup and scheduled work. Let the next person find the context

A price quote is more useful with the reason behind it. A client decision is more useful with the discussion that led to it. Recording this context helps colleagues pick up work when someone changes roles, instead of reconstructing it from scattered messages.

Sync through your own Drive

Changes sync hourly in both directions through your own Drive, with only changed information transferred. Each member keeps a local copy, and indexing and search remain local. Sharing is not instantaneous and does involve your Drive connection.

Start an organisation

An Enterprise plan holder can create the organisation and choose its engines. Anyone can join with an invite code, including users on Free. Members use the organisation’s pooled tasks and included features.

Pay per seat, pool the tasks

Enterprise is $29.99 per seat each month or $299.90 per seat yearly. Each seat contributes 3,000 monthly tasks to the shared allowance. CRM and History & memory are included. Images and video still use separate media credits.

Keep shared activity under control

The do-not-contact list applies across team sales activity. CRM permissions can distinguish viewing, editing, deleting, importing and sending campaigns. A synced campaign sends only from the machine that created it, helping prevent duplicate sends.
