Choose your device

Windows 10 and 11, Linux and Android are available. The Windows installer is version 2.49.53, 160 MB, released 17 October 2026. Linux AppImage and Android APK downloads are version 2.49.50. Mac and iPhone releases are being prepared but are not available to download yet.

Install on Windows

Download the installer and run it for your user account. Administrator access is not required by the standard installation. You can also use the published PowerShell installer: irm https://workforce.trackmystartup.com/install.ps1 | iex. Read the script first by removing the final | iex. It checks the downloaded file against its published SHA-256 before installing. There is no winget package.

Install on Linux

The AppImage supports x86_64 Intel and AMD machines; there is no ARM64 build. Check with uname -m, make the file executable with chmod +x Workforce-2.0-*.AppImage, then run it. You can also allow execution in file properties. Some distributions need libfuse2; the AppImage also supports --appimage-extract-and-run.

Open the app and start with one job

Open Workforce, connect the tools you want to use and describe the work you need. We select and connect the AI behind the task engines, so you do not need to compare models before getting started. You can add more connected tools as your work grows.

Connect only what you need

Sign in to Gmail, Drive, Calendar or another app when you want to use it. Account-free tools are available immediately. Start with draft-only permissions, then ask for one small job: find twenty relevant companies, summarize requests in this week’s inbox or check three competitors’ public prices.

Updates stay in your hands

The app checks for updates at launch and shows an Update button. Updates require your approval and keep your existing data and connections. Candidate changes are prepared separately. If an approved version fails to start twice, the app restores the previous version; earlier versions can also be restored manually.

Work with your existing files

Read Word, Excel, PowerPoint, PDF and CSV files, and read or update spreadsheets. Generated application documents are PDFs; Word export is not supported. Your local notes and files remain accessible if you stop using Workforce.
