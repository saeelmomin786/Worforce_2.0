Find customers and prepare campaigns

Sales finds companies, checks contact details, drafts outreach and prepares follow-ups. Finding leads is free; accepting one uses one task. Marketing studies your brand and competitors, creates a calendar and publishes approved posts. Each drafted post and competitor check uses one task; rendered media uses separate credits. Sales Enablement That Automates Your Outbound Pipeline

Make everyday admin easier

Inbox and replies reads selected Gmail mailboxes, keeps messages unread and drafts responses in your voice. Reading is free; each draft and sent message uses one task. Competitor prices reads public pricing pages and alerts you to changes. Finding competitors is free; accepting one and each check use one task.

Create content and prepare applications

Video studio turns an idea into a script, storyboard and editable clips. Planning uses tasks; renders use media credits. Job applications verifies live postings and prepares a tailored CV and cover letter. Finding listings is free; accepting one and each written document use one task. You submit the applications.

Build your business knowledge

SEO researches topics, drafts from your original evidence and helps publish reviewed articles. News follows your chosen topics, at one task per output. Expertise, also called Teach, applies the way you have taught it to perform a job, at one task per output. IPO analysis uses one task per IPO analysis and each data job. CRM and History & memory are included on Basic and above. CRM AI is not counted; building a memory file uses one task.

People, finance and service workflows

The marketplace includes HR, at one task per request and up to six requests an hour; Recruiting, at one task per output and up to four shortlists an hour; Bookkeeping, at one task per output and three batches an hour; Legal, at one task per document; and Customer support, at one task per answered ticket. Review important employment, legal and financial decisions with a qualified person.

The rest of the back office

Operations produces an hourly report, at one task per report. Procurement uses one task per output. Compliance runs up to four checks a day, at one task per output. Research uses one task per brief. Grants screens up to six opportunities daily, at one task per output. Investor relations uses one task per output, Startup one per deliverable, and Stock analysis one per report. Marketing (light) offers a shorter four-step workflow, at one task per output.

Workflows for software teams

Code review looks for correctness issues in a change. Design refresh audits an interface and proposes improvements. Investigate & fix traces a bug to its cause. Bloat audit identifies code that may be removed. These marketplace engines count output-producing steps as tasks and follow the same permissions.

Create a workflow of your own

Describe a name and the steps in ordinary language. Workforce builds a sequence of two to six steps and chooses the workers and apps needed. Outbound steps require approval by default. You can also save a routine, schedule work or commission an engine built for your business.
